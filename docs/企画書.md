# 企画書：グローバル・ビーコン日本版

> 架空の海外タブロイド紙が、実在する日本のニュースを壮大に読み違える。

---

## 1. コンセプト

海外メディアが日本を報じるとき、しばしば「禅」「武士道」「サムライ」「少子高齢化」といった手持ちの枠に押し込まれ、元の出来事から遠く離れた結論に着地する。

本企画は、その**「わかった気になっている側」の滑稽さ**だけを取り出して誇張したパロディサイトである。

出発点となった着想：

> 京大の卒業式で学生がうんちの仮装をする
> → 「日本最高学府の学生が単なる悪ふざけをするはずがない」
> → 「これは賢すぎるが故の、高度な記号論的抗議である」

**笑いの矛先は日本ではない。** 取材せずに断定する記者と、反証を受け付けない自称専門家である。

### 二重構造

| レイヤー | 内容 |
|---|---|
| 一段目 | 記事そのものの壮大な誤読 |
| 二段目 | 記事末尾の「読者コメント欄」で、日本人読者が身も蓋もない事実を一行で書いて全部壊す |

二段目があることで、読者は「正しい答え」を知った上で記事の暴走を眺めることになり、笑いが安全側に着地する。

## 2. 媒体設定（架空）

## 3. 「ズレた考察」を生む8つの型

これが企画の中身であり、記事を量産するためのエンジン。1記事につき3〜4個を組み合わせる。

| # | 型 | 挙動 |
|---|---|---|
| 1 | 禅・侘び寂び接続 | あらゆる事象を最終的に禅に着地させる |
| 2 | 武士道・起源説 | 起源をすべて武士に求める。時代考証は行わない |
| 3 | 過剰マクロ分析 | 少子高齢化・GDP停滞に接続し、独自の統計を出す |
| 4 | 賢すぎる故の皮肉説 | 「悪ふざけのはずがない、ゆえに高度な抗議だ」の三段論法 |
| 5 | 翻訳不可能信仰 | 「この語には英語に訳せない7つの層がある」 |
| 6 | 架空の専門家が断言 | 根拠なく結論。反論は載らない |
| 7 | 本国との比較オチ | 最後に必ず「わが国も学ぶべきでは」と手のひらを返す |
| 8 | 無関係な写真 | 「関連画像：東京の通勤客（2019年撮影）」 |

**文体は翻訳調で統一。** これが最大の武器。
「〜なのだ。」「かの有名な」「私は〜と言わざるを得ない」「30代の会社員、タナカ氏（仮名）は肩をすくめてこう言った。」

### 型の組み合わせ表（実装済み6記事）

| 記事 | 使用した型 |
|---|---|
| 京大・卒業式の仮装 | 4 → 1 → 3 |
| 列車の20秒早発と謝罪 | 2 → 5 → 7 |
| 甲子園の土 | 1 → 6 → 8 |
| 学校の掃除の時間 | 3 → 1 → 7（告発から始めて全面降伏） |
| 自動販売機400万台 | 6 → 8 → 7 |
| 渋谷のハロウィン | 2 → 5 → 3 |

## 4. 記事フォーマット

```
[キッカー]  独占調査 / 速報解説 / 現地ルポ / 科学 / 調査報道
[見出し]    タブロイド調・極太。断定形
[副題]      「専門家は警告する ——『これは、静かな反乱だ』」
[バイライン] 記者名／肩書／配信地・日
[リード]    3行で煽る
[元ネタ欄]  ← 実在の事象を明示する（誠実さの担保）
[考察の型]  ← 使用した型を開示する（種明かしを先にする）
[本文]      p / 中見出し / 引用 / 専門家コメント / 無関係な写真 / 謎の統計
[編集部注]  ← フィクション表明
[タグ]
[読者コメント（本紙による翻訳）]  ← 二段目の笑い
[次の誤読]
```

「元ネタ欄」と「考察の型」を**記事の冒頭に置く**のが本企画の設計上の要。
種明かしを先にすることで、読者は「これから壮大に外れる」と分かった上で読み、
かつ実在の事象への誤解を生まない。

---

## 5. 編集上の禁止事項

- 実在の個人・企業・団体の**発言を捏造しない**。引用符の中に入るのは、架空の記者・架空の専門家・架空の一般人（「タナカ氏（仮名）」）だけ。
- 特定の私人が識別できる題材は扱わない。広く報道された事象・慣習に限る。
- 国籍や民族に対する侮蔑的なステレオタイプは書かない。笑われるのは、常に取材しない側。
- 全ページ最上部に「PARODY」帯、各記事に「元ネタ」欄と「編集部注」を必ず置く。
- `<meta name="robots" content="noindex">` を全ページに付与し、検索経由で文脈なく読まれることを防ぐ。

## 6. 今後の拡張案

- **媒体を増やす** —— 独紙（規格と効率で読む）、仏紙（実存主義と革命で読む）、北欧紙（幸福度とワークライフバランスで読む）。同じニュースへの反応差そのものを笑いにする。
- **「本日の誤読」** —— トップに日替わりで1本を出す。
- **ズレ度メーター** —— 元の事実からの距離を★で表示。
- **元ネタ対比ビュー** —— 左に素っ気ない日本語の1行、右に壮大な考察。落差を一画面で見せる。

## 7. 技術構成

素の HTML / CSS / JavaScript。ビルド不要、依存ゼロ。GitHub Pages にそのまま公開できる。

```
index.html            トップ（一面＋記事一覧）
article.html          記事ページ（?id=kyodai-unchi で切替）
about.html            媒体設定・記者紹介・パロディ表明・8つの型の解説
assets/css/style.css  タブロイド風スタイル
assets/js/site.js     描画ロジック（DOM API のみ。innerHTML 不使用）
data/site.js          媒体設定
data/articles.js      記事データ
```

データを `.json` ではなく `.js`（グローバル代入）にしているのは、`fetch` が `file://`
で CORS に阻まれ、HTML をダブルクリックしただけでは動かないため。
サーバもビルドも要らずに開ける形を優先した。

記事の追加は `data/articles.js` に1オブジェクト足すだけでよい。
